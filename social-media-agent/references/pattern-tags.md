# Muster-Tags

Jeden eigenen und fremden Post mit diesen Tags versehen. Ergänzen, wenn ein Muster auftaucht, das nicht passt (neues Tag + Datum).

| Gruppe | Tags |
|---|---|
| Format | carousel, reel, einzelbild, story, text-only, screenrecording |
| Hook-Typ | frage, provokation, zahl, vorher-nachher, fehler-zeigen, rant, "ich-mache-X-live", frage-an-publikum, unerwarteter-vergleich |
| Gesicht | gesicht-ja, stimme-nur, kein-mensch |
| Look | roh (Handy, kein Schnitt), halb-poliert, studio |
| Länge | <10s, 10–30s, 30–60s, >60s; Carousel: Anzahl Slides |
| Thema | kritik-an-fremder-seite, eigener-prozess, kundenfall, preis, technik-erklärt, meinung, behind-the-scenes, schweiz-lokal |
| Spannung | konkret (echte Seite/Zahl), abstrakt (Versprechen) |
| CTA | keiner, dm, link-bio, kommentar, whatsapp |
| Zeit | Wochentag, Stunde (Europe/Zurich) |
| Distribution | hashtags-spezifisch, hashtags-generisch, keine, collab/tag |
| Auffälligkeit | **gegen-die-theorie** (Gewinner trotz "Fehler") / **erwartet-geflopt** (Flop trotz "Best Practice") |

Auswertungsmasse: Reichweite / Follower, Saves + Shares + Kommentare (zählen mehr als Likes), Profilbesuche, neue Follower, Link-Klicks, DMs, Erstgespräch-Anfragen.
